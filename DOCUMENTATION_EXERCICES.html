Choix de périmètre. Ces estimations décrivent le travail humain. Les minutes d'entraînement et de compression des GIF ne sont pas comptées comme du développement actif. Les exercices restent volontairement plus petits que le projet AstroDynamics.

Exécution

Les trois notebooks utilisent l'environnement uv commun :

uv sync --dev
cd EXERCICE_1  # ou EXERCICE_2 / EXERCICE_3
uv run jupyter lab

Chaque dossier contient son propre README, sa documentation HTML autonome et les artefacts correspondant à la dernière exécution complète.
